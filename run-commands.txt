==================================== RUN ORDER =====================================

Start services in this order:
  1. Python backend (GCN Kafka consumer)   → Terminal 1
  2. Node.js api-server (Express + WS)     → Terminal 2
  3. Frontend (Vite)                       → Terminal 3

IMPORTANT: Use a SEPARATE terminal for each service.
           Stop cleanly with Ctrl+C before restarting — do NOT close the window
           without stopping, or the port will stay blocked (WinError 10013).

If you get "WinError 10013" (port already in use), run:
  netstat -ano | findstr ":8001"     ← find the PID
  taskkill /F /PID <PID>             ← kill it
